# X/Twitter Thread — v2.9.1

1/6
Beluga AI v2.9.0 + v2.9.1 are out. Two workflow improvements and a stability patch. Here's what changed.

https://beluga-ai.org/blog/v2.9.1-release/

---

2/6
New in v2.9.0: `/consult` — a specialist routing command for Claude Code sessions.

When a session hits a domain boundary (security review, Go patterns, architecture), `/consult security` hands off to the right specialist and returns control when it's done. No context loss.

---

3/6
Also in v2.9.0: `/develop` now runs a Linear MCP pre-flight before creating a branch.

If the linked issue doesn't exist, is in a terminal state, or isn't assigned, it surfaces that — rather than quietly opening a branch against a stale work item.

---

4/6
Branch names in `/develop` are now derived from the Linear issue label, not free text at invocation time.

Label `feature/memory-ttl` on the issue → consistent, traceable branch name. One less thing to coordinate manually at the start of a task.

---

5/6
Also in v2.9.0: `dispatch-examples` is wired into the release workflow. When a framework release ships, the beluga-examples repo now rebuilds automatically against the new tag. No more manual trigger.

---

6/6
v2.9.1 (today): CI/stability patch. No API changes, no breaking changes.

CI now auto-updates CODE-QUALITY.md and SECURITY.md. Wiki housekeeping. Branch discipline docs consolidated. `corrections.md` split by category, all C-NNN IDs preserved.

Full post: https://beluga-ai.org/blog/v2.9.1-release/
