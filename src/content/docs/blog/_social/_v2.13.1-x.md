1/6
Beluga AI v2.13.1 is out. Two sprints of DX work: `beluga run/dev/test` adds a development loop with mock LLM support, and `beluga eval` ships a CLI-first evaluation framework.

2/6
Before v2.12.0, iterating on a Beluga agent meant hitting the real LLM API on every run. `beluga dev` changes that: mock LLM by default, hot-reload on changes, verbose trace output to stderr. Fast inner loop without API cost or latency.

3/6
The mock LLM registers as `"mock"` in the LLM registry — same interface as any real provider. Swap `"mock"` for `"anthropic"` and your test runs against the real API. No other code changes. Observability is also wired automatically when OTEL_EXPORTER_OTLP_ENDPOINT is set.

4/6
`beluga eval` (v2.13.0) is a CLI-first evaluation framework. `beluga new eval` scaffolds an eval harness for any existing agent. `beluga test ./...` picks up eval cases automatically alongside unit tests — evaluation as part of the standard loop, not a separate step.

5/6
v2.13.1 adds C-020 and C-021: framework-workflow documentation for the eval CLI — structural conventions, composition with `beluga test`, and the `eval/judge` handoff points. The features themselves are in v2.12.0 and v2.13.0.

6/6
No breaking changes. Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.1

Full release notes: https://beluga-ai.org/blog/v2.13.1-release/
