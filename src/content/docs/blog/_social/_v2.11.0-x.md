1/6
Beluga AI v2.11.0 is out. The headline: `beluga init` and `beluga new` scaffolding commands. New projects and new components from the command line, without copying boilerplate by hand.

2/6
Before this release, starting a Beluga project meant wiring up Go modules, provider config, observability bootstrapping, and a CLI entry point from scratch. Every team reinvented that setup. `beluga init` does it in one command.

3/6
`beluga new` handles component scaffolding — add an agent, a tool, or a provider to an existing project without writing the boilerplate struct and registration code yourself. The framework knows what a valid component looks like; now the CLI does too.

4/6
The scaffolding commands build on the Cobra CLI foundation shipped in v2.10.0, which also brought `beluga provider` and `beluga version` subcommands plus observability bootstrapping. v2.11.0 makes that foundation immediately useful to new users.

5/6
Also covered in this announcement window: v2.10.1 fixed the module path to `github.com/lookatitude/beluga-ai/v2`, and v2.10.2 shipped security hardening including removal of the UsageCount mutation.

6/6
No breaking changes. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.11.0

Full release notes: https://beluga-ai.org/blog/v2.11.0-release/
