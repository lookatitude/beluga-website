1/6 Beluga AI v2.13.2 ships `beluga eval` — a CLI for running LLM-as-Judge evaluations against agent outputs, with CI-ready reports.

2/6 `beluga eval` writes `eval-report.json` at the project root every run. Pass `--format junit` and you get JUnit XML that drops straight into GitHub Actions test reporters like dorny/test-reporter.

3/6 Under the hood it wires into the `eval/judge` package: rubric-driven scoring, per-row 30s timeouts, 5s protocol probe. Your project binary gets an eval branch scaffolded so the CLI knows how to invoke it.

4/6 This closes the DX-1 sprint:
- v2.10.0: Cobra CLI foundation
- v2.11.0: `beluga init` / `beluga new`
- v2.12.0: `beluga run`, `dev`, `test` + mock LLM + OTel bootstrap
- v2.13.0+: `beluga eval`

5/6 If you missed v2.12.0: `beluga dev` gives you a real iterative dev loop with the `llm/providers/mock` provider for offline testing and OTel wired up locally.

6/6 Upgrade:

go get github.com/lookatitude/beluga-ai/v2@v2.13.2
