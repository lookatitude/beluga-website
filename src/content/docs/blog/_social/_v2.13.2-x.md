1/6
Beluga AI v2.13.2 is out. The headline: `beluga run`, `beluga dev`, and `beluga test` close the inner dev loop. Plus a mock LLM provider for unit tests and `beluga eval` for evaluation suites. One CLI for the whole feedback cycle.

2/6
v2.11.0 made starting a project cheap. The next problem was iterating on agent behavior without juggling a build command, a runtime invocation, and a hand-rolled test harness. `beluga run` / `beluga dev` / `beluga test` collapse that into commands Go developers already expect.

3/6
`beluga dev` runs in development mode: verbose logs, observability bootstrapped to a local sink, and the mock LLM available as a fallback when no API key is set. Traces and metrics show up from the first invocation — no init code required.

4/6
The mock LLM provider registers under the same registry pattern as every other provider. Blank-import `github.com/lookatitude/beluga-ai/v2/llm/mock` in your test file and unit tests for multi-turn reasoning, tool calls, and guard policies run on every commit without an API key.

5/6
`beluga eval` runs an evaluation suite against your agent and reports pass/fail per case. First run scaffolds an `eval/` directory; subsequent runs execute the suite. Evaluation in the inner loop, not as a quarterly exercise.

6/6
Window covered: v2.11.1 through v2.13.2. No breaking changes. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
