1/6
Beluga AI v2.13.2 is out. The headline across this window: `beluga run/dev/test` for the inner developer loop, and `beluga eval` for agent evaluation. Iterate without burning real LLM API calls; evaluate from the command line.

2/6
v2.12.0 added `beluga run`, `beluga dev`, and `beluga test`. They use a mock LLM by default and bring up real observability — traces, metrics, logs — so you can run, develop, and test agents locally without paying per token on every iteration.

3/6
That changes the feedback loop. You write an agent, run it against the mock, watch spans appear in your local observability stack, and only swap in a real provider when you're ready to validate behavior end-to-end.

4/6
v2.13.0 shipped `beluga eval` plus a scaffolded eval branch in new projects. Agent evaluation gets a first-class CLI entry point instead of being something every team rebuilds.

5/6
v2.13.1 and v2.13.2 are documentation and maintenance updates following the eval CLI release. No API surface changes.

6/6
No breaking changes. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
