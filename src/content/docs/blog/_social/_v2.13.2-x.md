1/6
Beluga AI v2.12.0 + v2.13.0 ship the complete CLI developer loop: `beluga run`, `beluga dev`, `beluga test`, and `beluga eval`. Go from scaffold to evaluated agent output without leaving the terminal.

2/6
`beluga dev` runs your agent against a mock LLM — no API calls, no cost. Deterministic responses make it safe to use in CI. `beluga test` uses the same mock, so your test suite doesn't depend on external API availability.

3/6
Real OTLP tracing is wired in from day one. Set `BELUGA_OTEL_ENDPOINT` and `beluga run`, `beluga dev`, and `beluga test` all export traces. Local development now produces the same trace shape as production.

4/6
`beluga eval` (v2.13.0) adds evaluation to the loop. It runs your dataset through the configured metrics and reports per-metric scores. `beluga eval --scaffold` sets up the directory structure and starter dataset in one command.

5/6
The CLI is backed by the same `eval` package you already use in Go code — `EvalRunner`, `BatchJudge`, and metrics behave the same whether called from the terminal or from Go code. No behavioral gap between CLI and programmatic evaluation.

6/6
Full DX-1 arc complete: init → scaffold → run/dev/test → eval. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2
