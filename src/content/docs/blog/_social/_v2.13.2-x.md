1/6
Beluga AI v2.13.2 is out. The headline: `beluga eval` runs structured evaluation suites from the CLI, and `beluga run` / `beluga dev` / `beluga test` complete the dev loop. Building, testing, and evaluating agents now happens at the command line.

2/6
`beluga eval` (v2.13.0) drives the eval/judge package from the CLI. Define a suite, point the command at it, and get structured results back. No more hand-rolled scripts to wrap evaluation runs into CI.

3/6
`beluga run`, `beluga dev`, and `beluga test` shipped in v2.12.0. Run an agent, iterate on it with a dev loop, and execute Go test suites against it without leaving the CLI. The dev-loop story no longer requires per-project wiring.

4/6
`beluga test` injects a mock LLM. Test suites run offline, no API keys, no network. Deterministic agent tests in CI without paying per token or leaking secrets into pipelines.

5/6
Observability is automatic. The CLI reads `OTEL_*` env vars at startup and wires tracing and metrics. No boilerplate in main.go, no setup code to copy between projects.

6/6
No breaking changes. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
