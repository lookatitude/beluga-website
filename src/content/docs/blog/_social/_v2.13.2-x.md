1/6
Beluga AI v2.13.2 is out. The headline across this window: a real dev loop and an eval runner. `beluga run`, `beluga dev`, `beluga test`, and `beluga eval` — your agent project now has the same inner loop as any other Go project.

2/6
`beluga run` executes your agent program. `beluga dev` runs the same entry point with a mock LLM swapped in — no API keys, no network calls, traces and metrics to stdout. `beluga test` wires in mock providers so your test suite doesn't burn API credits. Shipped in v2.12.0.

3/6
All three bootstrap observability automatically. Tracing, metrics, and structured logs are on from the first run — you don't write the OTel setup yourself, and you don't forget to wire it before shipping.

4/6
v2.13.0 added `beluga eval`. Scaffolds an eval branch with example eval definitions, then runs them against your agent. Pairs with the `eval/judge` package already in the framework. Evaluations become part of the standard workflow, not a deferred item.

5/6
v2.11.1, v2.13.1, and v2.13.2 are CI and dependency patches — no API changes, safe to take. Together this window closes out DX-1 Sprints 3 and 4.

6/6
No breaking changes. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
