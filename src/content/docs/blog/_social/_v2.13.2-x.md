1/6
Beluga AI v2.13.2 is out. The headline: `beluga eval` — run LLM-as-Judge evaluations from the command line, no Go boilerplate required.

2/6
The eval/judge package has been in Beluga since v2.8.0, but running it meant writing your own harness: load rubrics, wire the judge, collect results, format output. v2.13.0 collapses that into one command.

3/6
`beluga eval init` scaffolds a structured eval branch — rubrics, fixtures, and config laid out so you can drop in test cases and run them. `beluga eval` executes the suite and reports scores. Evaluation is now part of the inner loop, not a side project.

4/6
Pair it with v2.12.0's `beluga run/dev/test` (mock LLM and observability bootstrapped by default) and the dev loop closes: code → run → test → evaluate. All four steps from one CLI.

5/6
Both releases are part of the DX-1 sprint focused on making the day-to-day developer experience match the framework's runtime maturity.

6/6
No breaking changes through v2.13.2. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
