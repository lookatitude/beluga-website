1/6
Beluga AI v2.13.2 is out. The headline: `beluga eval` — run structured evaluations against your agents from the command line. No custom harness, no ad-hoc scripts. Define a test suite, point it at an agent, get results.

2/6
This closes a DX arc that landed across three releases. v2.11.0: scaffold (`beluga init`, `beluga new`). v2.12.0: develop (`beluga run`, `beluga dev`, `beluga test`). v2.13.0: evaluate (`beluga eval`). The full agent lifecycle, covered by the CLI.

3/6
v2.12.0 is worth calling out on its own. `beluga dev` gives you a local dev loop with mock LLM support, so you can iterate on agent logic without model variation or token cost. `beluga test` wires up the test runner. `beluga run` executes agents with real observability bootstrapped automatically.

4/6
`beluga eval` builds on the scaffolded eval package shipped in v2.13.0. Structured evaluations — not vibes, not one-off prompts. Check agent behavior across a suite, track regressions, compare runs. That's what `beluga eval` closes: repeatable, structured measurement before a deployment.

5/6
v2.13.1 and v2.13.2 were documentation and CI maintenance. No API changes. No breaking changes across the window.

6/6
