1/6
Beluga AI v2.13.2 is out. The headline: `beluga eval`, a new CLI command for running evaluation suites against agents and pipelines from the command line.

2/6
Before this release, evaluating a Beluga agent meant writing a Go test harness around the `eval/judge` package, wiring up the suite runner yourself, and parsing results by hand. `beluga eval` runs the suite directly and prints structured output.

3/6
The command builds on the LLM-as-Judge package shipped in v2.8.0 and the Cobra CLI root from v2.10.0. Same scoring logic, same judge implementations, now reachable from a shell prompt and CI pipelines without custom Go scaffolding.

4/6
Use it to gate PRs on regression suites, score prompt or model swaps before they merge, and produce comparable numbers across runs. Output is structured for downstream tooling.

5/6
Also in this announcement window: v2.13.1 refreshed the docs for the new command, and v2.13.2 cleaned up CI configuration. No breaking changes across the v2.13.x series.

6/6
