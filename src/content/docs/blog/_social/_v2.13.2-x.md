1/7
Beluga AI v2.13.2 is out. The headline: the full inner dev loop now works from the `beluga` CLI. init, run, dev, test, eval — scaffold a project, iterate locally, evaluate it. The DX-1 series is complete.

2/7
v2.12.0 shipped `beluga run`, `beluga dev`, and `beluga test`. Local dev loop with hot-reload, a mock LLM so you can test without burning real API calls, and observability wired up from the first run instead of retrofitted later.

3/7
The mock LLM matters more than it sounds. Integration tests against real providers are slow, flaky, and expensive. `beluga test` runs your agents against a deterministic mock so CI stays green and cheap, and real provider calls stay opt-in.

4/7
v2.13.0 shipped `beluga eval`. Run it and it scaffolds an eval suite for your project, then executes it. Evaluation stops being something you bolt on after the fact and becomes part of the inner loop alongside run and test.

5/7
Recap of the DX-1 arc: v2.11.0 gave you `beluga init` and `beluga new` (scaffold projects and components). v2.12.0 gave you `run`, `dev`, `test` (iterate and verify). v2.13.0 gave you `eval` (measure). The CLI now covers every stage of building an agent locally.

6/7
v2.13.2 is the latest tag and covers everything above. No breaking changes from v2.11.0. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

7/7
