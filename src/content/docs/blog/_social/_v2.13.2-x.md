1/6
Beluga AI v2.13.2 is out. The headline across v2.12.0 and v2.13.0: a full inner dev loop on the CLI — `beluga run`, `beluga dev`, `beluga test`, and `beluga eval`. This closes the DX-1 series.

2/6
`beluga run` executes your Beluga program with production-equivalent config. `beluga dev` runs with the mock LLM — fast, offline, no API spend. `beluga test` wires Beluga projects into the standard Go test runner with the framework's conventions in place.

3/6
A built-in mock LLM lets `beluga test` and `beluga dev` run offline. No API keys, no token spend, deterministic output. Real OpenTelemetry bootstraps in the same path — traces work in dev exactly as they will in prod.

4/6
v2.13.0 adds `beluga eval`. Run an eval suite from the command line against any registered LLM provider. The release also scaffolded an `eval` branch for structuring suites alongside the project they test.

5/6
DX-1 arc, complete: `init` + `new` scaffold a project (v2.11.0). `run` + `dev` + `test` develop it locally (v2.12.0). `eval` measures output quality (v2.13.0). One CLI from empty directory to graded results.

6/6
No breaking changes. Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
