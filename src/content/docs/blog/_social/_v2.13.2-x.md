1/6
Beluga AI v2.13.2 is out. The headline: `beluga eval` — a CLI for scaffolding and running LLM evaluations, wired into Go's standard testing package. Eval suites now live next to your code and run with `go test`.

2/6
Scaffold an eval branch from the CLI, write cases as table-driven Go tests, and run them with the same tooling you already use for unit tests. No separate harness, no YAML DSL, no extra runner to learn.

3/6
The DX sprint that landed in v2.12 also ships in this line: `beluga run` for one-shot agent execution, `beluga dev` with hot reload, and `beluga test` with a mock LLM and observability bootstrap baked in.

4/6
In CI, the mock LLM removes API keys, rate limits, and token spend. Deterministic responses, no upstream flakiness. Run agent tests on every PR without burning tokens.

5/6
v2.13.1 and v2.13.2 are documentation and CI maintenance on top of v2.13.0. If you're already on v2.12, the upgrade is the eval CLI plus documentation and CI maintenance.

6/6
No breaking changes. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2
Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
