1/6
Beluga AI v2.13.2 is out. The headline across this window: `beluga eval` for running evaluation suites against agent output, plus `beluga run/dev/test` for the inner dev loop — the CLI now covers scaffolding, iteration, and evaluation end to end.

2/6
v2.13.0 added `beluga eval` and a scaffolded eval branch (DX-1 S4). Run an evaluation suite against agent output from the command line, get structured results back. No more handrolling test harnesses for every project.

3/6
v2.12.0 closed the inner dev loop (DX-1 S3): `beluga run` to execute, `beluga dev` for iteration, `beluga test` for verification. A mock LLM ships with it, so tests don't have to call a real provider to exercise agent logic.

4/6
v2.12.0 wired real OpenTelemetry bootstrapping: every model call, tool invocation, and handoff produces a span without additional code.

5/6
Together with `beluga init` and `beluga new` from v2.11.0, the CLI now spans the full local workflow: scaffold a project, scaffold a component, run it, iterate on it, test it, evaluate it.

6/6
No breaking changes from v2.11.0 through v2.13.2. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
