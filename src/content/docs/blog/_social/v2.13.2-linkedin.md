Beluga AI v2.13.2 ships two additions that address two recurring costs: token spend on the inner loop and harness boilerplate before evaluation.

Iterating on an agent has historically meant burning tokens on every run, even for changes that have nothing to do with model behavior. `beluga dev` (v2.12.0) runs against a mock LLM with no API key required, so the edit-save-run cycle costs nothing. `beluga test` runs the Go test suite. `beluga run` executes against a live LLM when you're ready to verify against real model output. All three commands bootstrap OpenTelemetry observability from environment variables automatically — traces and metrics are wired up from the first command.

`beluga eval` (v2.13.0) addresses the other recurring cost: writing an evaluation harness before you can measure anything. The subcommand scaffolds an `evals/` branch in the project and runs LLM evaluation suites from the terminal. It integrates with the `eval/judge` package, so LLM-as-Judge scoring plugs in directly without a separate harness.

No API changes in the v2.13.x window. Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2
