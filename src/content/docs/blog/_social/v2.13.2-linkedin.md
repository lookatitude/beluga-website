Beluga AI v2.13.2 ships today and closes out the CLI developer experience initiative that began with the Cobra foundation in v2.10.0. The full agent development loop now lives in the CLI, from scaffolding a new project to measuring agent quality against an evaluation suite.

The arc reads end to end:

- `beluga init` creates a new project with provider config, observability, and a CLI entry point in place.
- `beluga new` scaffolds agents, tools, and other components into an existing project.
- `beluga run` executes an agent against configured providers.
- `beluga dev` runs the same agent against a mock LLM with observability bootstrapped, so prompt and routing iteration happens without provider credits or network latency.
- `beluga test` runs unit tests against agent components with the framework test harness wired up.
- `beluga eval run` executes evaluation suites against an agent and reports results, moving quality measurement from one-off scripts to a first-class command.

Each command is documented in the reference docs, and the changelog from v2.12.0 through v2.13.2 covers the incremental additions. No breaking changes in this window.
