Beluga AI v2.9.1 ships today with one focused improvement: the beluga-examples repository now auto-syncs on every framework release.

Previously, example code could fall behind between releases. A developer cloning beluga-examples days after a new framework tag might encounter import paths or API signatures that had already changed. The new dispatch-examples CI job closes that gap by triggering an automatic update to beluga-examples whenever a new framework version is tagged. The result is that every example in the repo compiles against the current stable API without any manual intervention.

Supporting this release: fixes for merge commit handling and a goreleaser configuration issue that caused intermittent CI failures, plus knowledge layer housekeeping to keep internal reference material current.

There are no breaking changes in v2.9.1.

For teams building production agents in Go, reliable example code matters when onboarding engineers or evaluating new Beluga features. This release makes that baseline consistent across every version.

Full release notes: https://beluga-ai.org/blog/v2.9.1-release/
