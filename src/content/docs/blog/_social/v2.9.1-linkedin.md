# LinkedIn — v2.9.1

Beluga AI v2.9.0 and v2.9.1 shipped this week with two focused workflow improvements for teams running multi-agent Claude Code sessions against Linear-tracked work.

The first change is `/consult`, a new workspace command that routes a Claude Code session to a domain specialist — architect, go-developer, or security — and hands control back to the calling session when the specialist finishes. This addresses a coordination gap that shows up when a session reaches the edge of its own domain and needs targeted expert input rather than an approximation.

The second change extends `/develop` with a Linear MCP pre-flight check. Before opening a branch, `/develop` now validates that the linked issue exists, is not in a terminal state, and is assigned. Branch names are also derived from the Linear issue label directly, producing consistent names without manual coordination at task start.

The `dispatch-examples` workflow change means the beluga-examples repository now rebuilds automatically on each framework release rather than requiring a separate manual trigger.

v2.9.1 is a stability patch: no Go API changes, no breaking changes. CI now auto-updates CODE-QUALITY.md and SECURITY.md, wiki housekeeping is done, and branch discipline documentation is consolidated under a single file.

Full release notes: https://beluga-ai.org/blog/v2.9.1-release/
