Beluga AI v2.13.2: `beluga dev` runs an agent against a mock LLM with no API key — no token spend on the inner loop. `beluga test` runs the Go suite. `beluga run` executes against a live LLM. All three bootstrap OpenTelemetry from env vars automatically.

2/3
`beluga eval` scaffolds an `evals/` branch and runs LLM evaluation suites from the terminal. Integrates with the `eval/judge` package for LLM-as-Judge scoring — no separate harness. go get github.com/lookatitude/beluga-ai/v2@v2.13.2
