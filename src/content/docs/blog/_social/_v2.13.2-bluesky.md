Beluga AI v2.13.2 is out. v2.13.0 added `beluga eval` for running evaluation suites against agent output from the CLI. v2.12.0 closed the inner dev loop with `beluga run`, `beluga dev`, and `beluga test`, plus a mock LLM and real observability bootstrapping.

2/3
With v2.11.0's `beluga init` and `beluga new` already in place, the CLI now covers the full local workflow: scaffold, run, iterate, test, evaluate. No breaking changes across the v2.11.0–v2.13.2 window.
