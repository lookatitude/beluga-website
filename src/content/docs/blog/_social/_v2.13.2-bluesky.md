1/3 Beluga AI v2.13.2 ships `beluga eval`: a CLI for running LLM-as-Judge evaluations against agent outputs. Always writes `eval-report.json` at project root. `--format junit` emits JUnit XML for GitHub Actions test reporters.

2/3 Built on the `eval/judge` package — rubric-driven scoring, per-row 30s timeout, 5s protocol probe. The CLI scaffolds an eval branch in your project binary so it knows how to run.

3/3 Closes the DX-1 series (init/new → dev loop + mock LLM + OTel → eval).
