Beluga AI v2.13.2: the Beluga Eval CLI (shipped in v2.13.0) scaffolds and runs evaluation suites. `beluga eval init <name>` creates a suite; `beluga eval run` executes it with CI-compatible exit codes. Built-in judges: `Contains`, `ExactMatch`, `Similarity`. Custom judges implement `judge.Judge`.
