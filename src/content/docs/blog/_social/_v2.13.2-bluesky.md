1/3
Beluga AI v2.13.2: the inner dev loop ships. `beluga run` executes your program; `beluga dev` re-runs on file changes; `beluga test` plugs into `go test`. Built-in mock LLM for offline runs. Real OpenTelemetry bootstraps in the same path.

2/3
`beluga eval` (v2.13.0) runs an eval suite from the CLI against any registered LLM provider. With the v2.11.0 `init`/`new` scaffolding, the DX-1 arc is complete: empty directory → run → test → eval, all from one binary.

3/3
No breaking changes. go get github.com/lookatitude/beluga-ai/v2@v2.13.2
