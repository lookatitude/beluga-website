Beluga AI v2.13.2 is out. `beluga run`, `beluga dev`, and `beluga test` close the inner dev loop. A mock LLM provider takes API calls out of unit tests. `beluga eval` runs evaluation suites against the agent from the same CLI.

2/3
The mock provider registers through the same pattern as every real backend — blank-import it and unit tests for reasoning, tool calls, and guard policies run on every commit without an API key. `beluga eval` scaffolds an `eval/` directory on first use, then runs the suite with per-case verdicts.
