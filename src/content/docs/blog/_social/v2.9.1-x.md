1/6
Beluga AI v2.9.1 is out. The headline: beluga-examples now auto-syncs on every framework release. Every example in the repo compiles against the current stable API, automatically.

2/6
Before v2.9.0, example code could fall behind after a release. Developers cloning beluga-examples days later might hit import errors from an API that had already moved.

3/6
The fix is dispatch-examples: a new CI job in the framework release workflow that sends a repository_dispatch to beluga-examples on every tag. The examples repo picks it up and updates its go.mod to the new release.

4/6
Supporting changes in v2.9.1: merge commit handling and a goreleaser ref fix that were causing intermittent CI failures. No API changes, no breaking changes.

5/6
Knowledge layer housekeeping is also included: stale wiki artifacts removed, corrections split into categories.

6/6
No breaking changes. Update with: go get github.com/lookatitude/beluga-ai@v2.9.1

Full release notes: https://beluga-ai.org/blog/v2.9.1-release/
