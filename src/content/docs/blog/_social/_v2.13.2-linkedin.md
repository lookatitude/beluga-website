Beluga AI v2.13.2 ships today, closing out a release window focused on the local developer workflow.

v2.13.0 introduced `beluga eval`, a CLI command for running evaluation suites against agent output, along with a scaffolded eval branch (DX-1 S4). Teams can now define evaluation cases and execute them from the command line as a normal step in their workflow, rather than building a custom harness for each project.

v2.12.0 filled in the inner dev loop (DX-1 S3) with `beluga run`, `beluga dev`, and `beluga test`. The release includes a mock LLM, so tests can exercise agent logic without round-tripping to a real provider, and it wires up real observability bootstrapping in place of the placeholder setup that previously sat in starter projects.

Together with the `beluga init` and `beluga new` scaffolding commands from v2.11.0, the CLI now spans the full local workflow: project scaffold, component scaffold, run, iterate, test, and evaluate.

No breaking changes from v2.11.0 through v2.13.2.

Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2
