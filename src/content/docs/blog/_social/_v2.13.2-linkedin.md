Beluga AI v2.13.2 ships today and completes the DX-1 developer experience series. The full inner dev loop for building agents now runs from the `beluga` CLI: init, run, dev, test, eval.

v2.12.0 added `beluga run`, `beluga dev`, and `beluga test`. The dev command gives you a local iteration loop; the test command runs against a deterministic mock LLM, so integration tests no longer require burning real API calls or tolerating provider flakiness in CI. Observability is bootstrapped on first run rather than retrofitted later.

v2.13.0 added `beluga eval`. Running it executes the evaluation suite that `beluga init` scaffolded, making evaluation part of the inner loop alongside running and testing — not a separate process configured months after the agent ships.

Read together with v2.11.0 (`beluga init` and `beluga new` for project and component scaffolding), the CLI now covers every stage of local agent development: scaffold, run, test, evaluate. v2.13.2 is the latest tag covering all of the above, with no breaking changes from v2.11.0.

Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2
