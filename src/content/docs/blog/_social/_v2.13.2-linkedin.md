Beluga AI v2.13.2 ships today. The headline feature, introduced in v2.13.0, is the Beluga Eval CLI: a first-class way to define and run evaluation suites for agents and pipelines from the command line.

`beluga eval init <name>` scaffolds a suite — cases, judges, configuration — into your repository. `beluga eval run` executes the suite against your code and reports per-case results. Three judges ship by default: `Contains` for substring assertions, `ExactMatch` for strict comparisons, and `Similarity` for fuzzy semantic checks. Custom judges implement the `judge.Judge` interface, so model-graded judges, regex validators, and structured-output checks compose the same way as the built-ins.

`beluga eval run` returns CI-compatible exit codes. That makes evaluation a CI gate alongside unit tests, rather than a manual step that drifts out of sync with the codebase.

v2.13.1 and v2.13.2 are documentation and audit updates with no API changes. There are no breaking changes across the v2.13.x line.
