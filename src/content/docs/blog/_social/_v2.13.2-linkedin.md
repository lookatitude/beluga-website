Beluga AI v2.13.2 ships today. The headline across this announcement window is a working dev loop for agent code, plus a CLI for running evaluations.

v2.12.0 added `beluga run`, `beluga dev`, and `beluga test`. `beluga run` executes your agent program. `beluga dev` runs the same entry point with a mock LLM provider swapped in — no API keys, no network calls — and emits traces and metrics to stdout for local inspection. `beluga test` wires in a mock LLM, so the test suite doesn't call real providers or burn API credits during CI. All three bootstrap observability automatically — tracing, metrics, and structured logs are configured before your code runs.

v2.13.0 added `beluga eval`. The command scaffolds an eval branch with example eval definitions, then runs them against your agent. It pairs with the `eval/judge` package already in the framework. Evaluations become part of the standard workflow, not a deferred item.

v2.11.1, v2.13.1, and v2.13.2 are CI and dependency patches — no API changes, safe to take.

Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2
