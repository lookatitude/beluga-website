Beluga AI v2.13.2 ships today, completing the v2.12.0–v2.13.2 release window with a working developer loop for agent projects.

`beluga run` builds and execs a scaffolded project with signal forwarding. `beluga dev` adds a file-watch rebuild/restart loop and a loopback playground UI that surfaces OTel spans, stderr, and cost panels as you iterate. `beluga test` pins the test environment (`BELUGA_LLM_PROVIDER=mock`, `OTEL_SDK_DISABLED=true`) so suites run offline with no API key, paired with a new `llm/providers/mock` provider that replays FIFO fixture queues for deterministic scenarios.

v2.13.0 added `beluga eval`, which runs the eval/judge pipeline from the CLI and scaffolds an eval branch with test datasets and judge config in place. `o11y.BootstrapFromEnv` now ships real OTLP/HTTP and stdout exporters with a no-op fallback. The integration matrix covers Ubuntu, macOS, and Windows.

This is sprint 4 of the DX-1 initiative: CLI foundation (v2.10.0), scaffolding (v2.11.0), dev loop (v2.12.0), eval CLI (v2.13.0). v2.11.1, v2.13.1, and v2.13.2 were maintenance.

No breaking changes. Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
