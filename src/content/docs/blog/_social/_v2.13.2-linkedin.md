Beluga AI v2.13.2 ships today, closing out a four-release window focused on the developer inner loop and agent evaluation.

Iterating on an agent traditionally meant a choice between mocking the LLM by hand or paying for real API calls on every code change. Neither scales. Mocks drift from real provider behavior; real calls slow down iteration and run up costs before the agent is ready for end-to-end validation.

v2.12.0 introduced `beluga run`, `beluga dev`, and `beluga test`. The commands default to a mock LLM and bring up real observability — traces, metrics, and logs — so developers can run, develop, and test agents locally with full visibility and without per-token charges during iteration. Real providers swap in when the agent is ready for behavioral validation.

v2.13.0 added `beluga eval` and a scaffolded eval branch for new projects, giving agent evaluation a first-class command-line entry point. v2.13.1 and v2.13.2 followed with documentation and maintenance updates; no API surface changes.

No breaking changes across the window.

Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
