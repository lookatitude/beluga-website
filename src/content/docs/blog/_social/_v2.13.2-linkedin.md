Beluga AI v2.13.2 ships today, completing the dev-loop and evaluation story for the CLI.

`beluga eval`, introduced in v2.13.0, runs structured evaluation suites from the command line. It drives the framework's eval/judge package directly, so suites that previously required hand-rolled scripts now execute through a single command and return structured results suitable for CI.

The v2.12.0 release added `beluga run`, `beluga dev`, and `beluga test`. Together they cover running an agent, iterating on it with a dev loop, and exercising it through Go test suites. `beluga test` injects a mock LLM, which lets test suites run offline without API keys and produces deterministic results in CI without per-token cost.

Observability wiring is now automatic. The CLI reads `OTEL_*` environment variables at startup and configures tracing and metrics without any code in `main.go`. Projects pick up consistent observability without copying setup code between repositories.

No breaking changes in this window.

Upgrade: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
