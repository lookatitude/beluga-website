Beluga AI v2.13.2 ships today with `beluga eval`, a new CLI command for running evaluation suites against agents and pipelines.

Before this release, evaluating a Beluga agent meant writing a Go test harness around the `eval/judge` package, wiring up the suite runner yourself, and parsing results by hand. Teams who wanted to gate PRs on regression suites or score prompt and model swaps had to build that integration before they could measure anything. The work was repetitive, with no standard harness to share across projects.

`beluga eval` runs evaluation suites directly from the command line and prints structured output suitable for CI pipelines and downstream tooling. The command builds on the LLM-as-Judge package introduced in v2.8.0 and the Cobra CLI root from v2.10.0, so the scoring logic and judge implementations are the same code paths available in the `eval/judge` package — accessible from a shell prompt without custom Go scaffolding.

This announcement also covers v2.13.1 (documentation refresh for the new command) and v2.13.2 (CI housekeeping). No breaking changes across the v2.13.x series.
