Beluga AI v2.13.2 closes out the DX-1 CLI initiative. Across v2.12.0 and v2.13.0, the framework gained a full inner development loop on the command line.

v2.12.0 introduced `beluga run`, `beluga dev`, and `beluga test`. `run` executes a Beluga program; `dev` re-runs on file changes for tight iteration; `test` integrates Beluga projects with the standard Go test runner. A built-in mock LLM lets developers exercise their code offline — no API keys, no token spend, deterministic responses — while the same code path bootstraps real OpenTelemetry, so traces behave in development the way they will in production.

v2.13.0 added `beluga eval`, which runs an evaluation suite against any registered LLM provider from the CLI, plus a scaffolded `eval` branch for organizing suites alongside the project they test.

Combined with the `beluga init` and `beluga new` scaffolding from v2.11.0, this completes a single-CLI path from empty directory to a project you can run, test, debug, and grade.
