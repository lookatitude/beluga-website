1/6
Beluga AI v2.13.2 closes out the CLI DX initiative. The full agent loop now lives in the CLI: `beluga init` to scaffold, `beluga new` to add components, `beluga dev` to iterate, `beluga eval` to measure quality.

2/6
`beluga run` and `beluga dev` shipped in v2.12.0. `dev` runs your agent against a mock LLM with real observability bootstrapped, so you can iterate on prompts, tools, and routing logic without burning provider credits or waiting on network round-trips.

3/6
`beluga test` came in the same release. Runs unit tests against your agent components with the framework's test harness wired up — no manual fixture assembly per project.

4/6
v2.13.0 added `beluga eval run`. Point it at an evaluation suite, and it runs the suite against your agent and reports the results. Quality measurement moves from one-off scripts to a first-class CLI command.

5/6
The arc since v2.10.0: Cobra CLI foundation → `beluga init` / `beluga new` (v2.11.0) → dev loop (v2.12.0) → eval (v2.13.0). v2.13.2 is the maintenance tag that wraps it up. No breaking changes.

6/6
