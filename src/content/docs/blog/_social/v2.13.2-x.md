1/6
Beluga AI v2.13.2 is out. Two headline additions in this window: `beluga eval` for running LLM evaluation suites from the terminal, and a `beluga run`/`dev`/`test` dev loop that mirrors the way most Go projects already work.

2/6
`beluga dev` runs an agent against a mock LLM. No API key, no provider account, no per-iteration token spend on the inner loop. Edit, save, run, repeat — same iteration pattern as any other Go service.

3/6
`beluga test` runs the Go test suite. `beluga run` executes against a live LLM when ready. All three commands bootstrap OpenTelemetry from environment variables automatically, so traces and metrics are wired up on first run.

4/6
`beluga eval` (v2.13.0) is the other half. One command scaffolds an `evals/` branch in the project and runs LLM evaluation suites from the CLI. No boilerplate harness to write before scoring outputs.

5/6
The eval CLI integrates with the `eval/judge` package — LLM-as-Judge scoring plugs in directly, so outputs can be graded against rubrics without standing up a separate evaluation service.

6/6
No API changes in the v2.13.x window. Update with: go get github.com/lookatitude/beluga-ai/v2@v2.13.2

Full release notes: https://beluga-ai.org/blog/v2.13.2-release/
